# 星云科技招聘与入职流程

## 一、招聘流程

### 1.1 岗位发布
招聘需求由部门负责人发起，经HR和CEO审批后发布。发布渠道：
- 星云科技官网招聘页
- 拉勾网、Boss直聘
- 内部推荐渠道（推荐成功奖励3000元）

### 1.2 面试流程
技术岗位面试共4轮：

| 轮次 | 面试人 | 内容 | 时长 |
|------|--------|------|------|
| HR初筛 | HR专员 | 基本信息核实、薪资预期沟通 | 15-20分钟 |
| 技术一面 | 团队技术骨干 | 编程能力考察（算法+项目经验） | 60分钟 |
| 技术二面 | 技术Leader | 系统设计+架构思维考察 | 45分钟 |
| 终面 | 部门总监+HRBP | 综合评估+薪资谈判 | 30分钟 |

### 1.3 非技术岗位
产品、设计、运营等岗位面试3轮：HR初筛 → 专业面试 → 终面。

## 二、入职流程

### 2.1 入职前准备
入职前3天，HR会通过邮件发送以下材料：
1. 劳动合同（电子版，飞书签字）
2. 入职指引手册
3. 飞书账号邀请
3. 需提交材料清单：
   - 身份证正反面扫描件
   - 最高学历证书扫描件
   - 近3个月社保缴纳记录（或离职证明）
   - 体检报告（二级以上医院，3个月内有效）

### 2.2 入职当天
入职第一天流程安排：

| 时间 | 事项 | 负责人 |
|------|------|--------|
| 09:30 | 签署劳动合同 | HR专员 |
| 10:00 | 领取办公设备（电脑+显示器） | IT部门 |
| 10:30 | 飞书账号开通+权限配置 | IT部门 |
| 11:00 | 部门介绍+团队见面 | 直属Leader |
| 12:00 | 新人午餐（部门聚餐） | 团队 |
| 14:00 | 新人培训：公司文化+制度 | HR |
| 15:00 | 新人培训：安全制度+IT规范 | 安全团队 |
| 16:00 | 开发环境搭建 | 导师 |

### 2.3 导师制度
每位新员工配备一位入职导师（Mentor），为期3个月：
- 导师由团队资深工程师（P7及以上）担任
- 导师职责：协助环境搭建、解答技术疑问、融入团队文化
- 每周至少1次1-on-1沟通（30分钟）
- 导师补贴：每月额外500元

### 2.4 试用期
- 试用期时长：3个月（P8及以上为6个月）
- 试用期薪资：100%发放（无折扣）
- 试用期考核：由直属Leader + HRBP 共同评估
- 试用期通过标准：
  - 完成至少1个独立任务交付
  - 代码评审通过率≥80%
  - 团队协作评分≥B级

## 三、离职流程

### 3.1 离职申请
员工需提前30天提交离职申请（飞书审批流程）。试用期员工需提前3天。

### 3.2 离职交接
- 工作交接清单由直属Leader制定
- 交接内容包括：项目文档、代码仓库权限、客户关系、未完成任务
- 交接需离职前5个工作日完成
- 交接完成后由Leader签字确认

### 3.3 离职清算
- 最后薪资于次月15日发放
- 年假折算：未使用年假按日薪折算补偿
- 期权处理：已vest部分保留，未vest部分失效
