# 星云科技员工行为准则与职业道德

## 一、核心价值观

星云科技倡导四大核心价值观：

1. **极致创新** - 不满足于现有方案，持续追求更好的技术解
2. **坦诚协作** - 信息透明，直接沟通，拒绝办公室政治
3. **用户至上** - 产品决策始终以用户价值为第一优先级
4. **长期主义** - 短期利益不牺牲长期竞争力

## 二、职业道德

### 2.1 诚信原则
- 禁止在工作时间、工作成果上造假（包括虚报工时、伪造实验数据）
- 禁止夸大产品能力或隐瞒已知缺陷
- 发现同事违反诚信原则，应向HR或合规部门报告（不视为"告密"，视为组织健康维护）

### 2.2 利益冲突
- 员工不得在公司之外从事与公司业务竞争的工作
- 员工不得利用公司资源为个人或第三方牟利
- 员工投资公司竞争对手需提前向合规部门报备
- 收到供应商礼品超过200元需向合规部门报备

### 2.3 保密义务
- 员工在职期间及离职后2年内，不得向第三方披露公司商业秘密
- 商业秘密包括但不限于：技术架构、算法细节、客户数据、财务数据、战略规划
- 离职时需签署保密确认书，违反保密义务需承担法律责任

## 三、办公行为规范

### 3.1 沟通礼仪
- 飞书消息24小时内必须回复（紧急消息30分钟内）
- 会议准时参加，迟到需提前通知
- 邮件书写规范：标题明确、正文简洁、必要信息不遗漏
- 禁止在工作群发送无关内容（广告、谣言、低俗内容）

### 3.2 着装规范
- 日常办公：休闲着装即可（禁止穿拖鞋、超短裤/裙）
- 客户拜访/重要会议：商务休闲（衬衫/西装外套）
- 实验室/机房：按安全规范着装（禁止穿裙子、必须穿绝缘鞋）

### 3.3 办公环境
- 保持桌面整洁，不堆放个人杂物
- 公共区域（会议室、茶水间）使用后恢复原状
- 禁止在办公区吸烟、饮酒
- 宠物不可带入办公区（特殊情况需HR审批）

## 四、知识产权

### 4.1 工作成果归属
员工在职期间使用公司资源（时间、设备、数据）创造的所有知识产权（代码、文档、设计、算法）归公司所有。

### 4.2 开源贡献
- 使用公司资源产生的开源贡献需经技术委员会审批
- 个人业余时间独立完成的开源项目归个人所有
- 不得将公司私有代码混入个人开源项目

### 4.3 专利
- 公司鼓励员工申请专利，专利申请费用由公司承担
- 发明人奖励：发明专利5000元/项，实用新型2000元/项
- 专利归属公司，发明人享有署名权

## 五、举报与投诉

### 5.1 举报渠道
- 飞书匿名举报通道（合规部门专用）
- 直接向HRBP反映
- 向部门负责人反映

### 5.2 举报保护
- 公司保护举报人身份，禁止任何形式的报复行为
- 对报复举报人的行为，一经查实，解除劳动合同
- 举报内容查实后，举报人可获得1000-5000元奖励

### 5.3 投诉处理时效
- 普通投诉：7个工作日内回复
- 紧急投诉（涉及人身安全/重大违规）：24小时内启动调查
