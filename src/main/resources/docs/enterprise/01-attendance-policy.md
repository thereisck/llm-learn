# 星云科技员工考勤与休假管理制度

## 一、考勤制度

### 1.1 工作时间
公司实行弹性工作制，核心工作时间为 **10:00-16:00**。员工需在此时间段内保证在岗，其余时间可自由安排。每日实际工作时间不得少于8小时。

### 1.2 考勤方式
- 采用飞书考勤打卡，每日打卡两次（上班+下班）
- 打卡地点：公司办公区域范围内（GPS定位）
- 未打卡视为缺勤，需当日提交飞书补卡申请并说明原因

### 1.3 迟到与早退
- 迟到10分钟以内：不扣薪，但计入月度考勤统计
- 迟到10-30分钟：扣当日0.5小时薪资
- 迟到超过30分钟：按旷工半天处理
- 早退规则同迟到规则

## 二、休假制度

### 2.1 年假
- 入职满1年：5天年假
- 入职满3年：10天年假
- 入职满5年：15天年假
- 年假当年未使用部分可延续至次年第一季度，逾期清零
- 年假需提前3个工作日在飞书提交审批

### 2.2 病假
- 每年带薪病假3天，不需医院证明
- 超过3天需提供二级以上医院诊断证明
- 病假期间发放基本工资的80%

### 2.3 事假
- 事假为无薪假，需提前1个工作日申请（紧急情况除外）
- 月度事假累计超过3天需部门负责人审批
- 年度事假累计超过10天将影响年度绩效评级

### 2.4 产假与陪产假
- 女员工产假：158天（含法定98天+公司额外60天）
- 男员工陪产假：15天
- 产假/陪产假期间发放全额薪资

## 三、加班管理

### 3.1 加班申请
加班需提前1个工作日通过飞书提交加班申请，经直属领导审批后方可执行。

### 3.2 加班补偿
- 工作日加班：按1.5倍薪资计算加班费，或可选择调休（1:1）
- 周末加班：按2倍薪资计算加班费，或可选择调休（1:1.5）
- 法定节假日加班：按3倍薪资计算，不可选择调休
- 调休需在加班后30天内使用完毕

## 四、远程办公

### 4.1 远程办公条件
- 每周最多2天远程办公（需部门负责人同意）
- 核心工作时间（10:00-16:00）必须在线响应
- 远程办公日不计入考勤打卡，但需在飞书签到

### 4.2 远程办公工具
- 飞书（沟通+文档协作）
- VS Code Remote（开发环境）
- 公司VPN（访问内网资源）
