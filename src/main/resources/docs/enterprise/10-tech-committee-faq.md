# 星云科技技术委员会 FAQ

以下是技术委员会常见问题的官方答复。

## Q1：技术委员会是什么？
技术委员会是星云科技的技术决策机构，由 CTO + 5名技术总监组成。职责包括：技术选型审批、架构评审、开源项目审批、技术文化推广。

## Q2：如何申请技术选型变更？
当你需要引入新技术（新框架、新数据库、新中间件）时，需提交技术选型申请：
1. 在飞书文档中填写《技术选型评估表》
2. 包含以下内容：需求背景、候选方案对比表、性能测试数据、风险评估、迁移计划
3. 提交给技术委员会，7个工作日内批复
4. 当前已审批的技术栈清单可在飞书知识库查看

## Q3：当前官方技术栈是什么？
后端：Java 17 + Spring Boot 3.2 + MyBatis-Plus + Redis + MySQL 8.0
前端：React 18 + TypeScript + Ant Design 5
基础设施：Kubernetes + Docker + WireGuard VPN + Prometheus + Grafana
AI 相关：LangChain4j + Chroma + SiliconFlow API + OpenAI API

## Q4：我能自己选技术方案吗？
小型项目（3人以内、3个月以内）可以自主选型，但需在项目文档中记录选型理由。
中型项目（3-10人）需技术Leader审批。
大型项目（10人以上）需技术委员会审批。

## Q5：代码评审被拒绝了怎么办？
代码评审被拒绝是正常现象，不代表你能力不行。处理方式：
1. 仔细阅读Reviewer的每条意见
2. 有疑问的通过飞书1-on-1讨论，不要在MR评论区争论
3. 修改后重新提交，不要在同一MR上反复push（超过5轮自动关闭）
4. 如果认为Reviewer意见不合理，可申请第三方Review（找另一名P7+）

## Q6：如何申请加班？
加班申请流程：飞书审批 → 直属Leader审批 → HR备案。注意事项：
- 必须提前1个工作日申请（紧急情况可后补，但需24小时内补申请）
- 加班时段必须在飞书签到
- 加班后30天内完成调休或领取加班费

## Q7：测试环境和生产环境的区别是什么？
- 测试环境（staging）：使用Mock数据，可自由操作，不影响真实用户
- 生产环境（prod）：真实数据，所有操作有审计日志，访问需通过堡垒机
- 禁止在测试环境使用生产数据（即使脱敏也需审批）
- 禁止在生产环境做调试（看日志通过 Grafana + ELK）

## Q8：项目紧急时能否跳过代码评审？
技术委员会明确规定：任何代码进入生产环境都必须经过Code Review，没有例外。
紧急情况下可以：
- 缩短Review时间（从48小时降到4小时）
- 只Review核心变更（非核心部分后续补Review）
- 但绝不能完全跳过

## Q9：如何报告安全漏洞？
发现安全漏洞时：
1. 不要在公开渠道（飞书群、GitHub Issue）报告
2. 通过飞书安全团队专用频道或邮件 security@starcloud.ai 报告
3. 包含：漏洞描述、影响范围、复现步骤、建议修复方案
4. 30分钟内安全团队响应
5. P0级别漏洞15分钟内CTO响应

## Q10：远程办公需要注意什么？
远程办公规则：
- 每周最多2天，需Leader同意
- 核心工作时间（10:00-16:00）必须在线
- 需在公司VPN环境下办公（禁止公共WiFi）
- 视频会议必须开摄像头
- L3+数据禁止在远程办公日下载到本地
