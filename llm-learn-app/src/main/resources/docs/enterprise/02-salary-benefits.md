# 星云科技薪酬与福利体系

## 一、薪酬结构

员工薪酬由以下几部分构成：

### 1.1 基本工资
基本工资占薪酬总额的60%，根据岗位级别确定：

| 级别 | 基本月薪范围 | 适用人群 |
|------|-------------|----------|
| P5 | 8,000-12,000 | 初级工程师 |
| P6 | 12,000-18,000 | 中级工程师 |
| P7 | 18,000-28,000 | 高级工程师 |
| P8 | 28,000-45,000 | 专家/架构师 |
| P9 | 45,000-70,000 | 首席专家/技术总监 |

### 1.2 绩效奖金
绩效奖金占薪酬总额的20%，每季度发放一次。计算公式：

**绩效奖金 = 基本月薪 × 3 × 绩效系数**

绩效系数根据季度评级确定：
- S（卓越）：1.5
- A（优秀）：1.2
- B（达标）：1.0
- C（待改进）：0.5
- D（不合格）：0

### 1.3 年终奖
年终奖占薪酬总额的20%，每年1月发放。计算公式：

**年终奖 = 基本月薪 × 2 × 年度绩效系数 × 公司经营系数**

公司经营系数由年度营收目标完成率决定，范围0.5-2.0。

## 二、福利体系

### 2.1 五险一金
- 社保：按实际薪资基数缴纳，公司承担部分为个人部分的2倍
- 公积金：12%缴纳比例（公司+个人各12%）

### 2.2 商业保险
- 每位员工配备50万保额意外险
- 补充医疗保险：覆盖社保目录外药品，年度限额5万
- 重大疾病险：保额30万

### 2.3 健康关怀
- 每年1次免费体检（价值约2000元）
- 公司健身房免费使用（包含淋浴）
- 每月200元健身补贴（需提交健身记录）

### 2.4 学习与发展
- 每年5000元学习基金（购书、课程、认证考试）
- 技术大会参会补贴：国内2000元/次，海外8000元/次
- 内部技术分享奖励：主讲人500元/次

### 2.5 生活福利
- 每日15元午餐补贴（飞书自动发放）
- 每月100元交通补贴
- 每季度500元团建基金
- 生日月享受200元蛋糕补贴
- 茶水间免费供应咖啡、茶、零食

### 2.6 股权激励
入职满2年且绩效评级A及以上者，可纳入期权激励计划。期权分4年 vesting，每年解锁25%。
