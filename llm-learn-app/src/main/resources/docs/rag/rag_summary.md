# 阶段一：RAG 核心链路复盘
## 1. 原始文档
## 2. Document Loader
    负责把pdf、mardown、网页、数据库记录等变成统一文本。
## 3. Chunk Splitter
    决定知识被切分成什么粒度，被切坏了，后面全废。
## 4. Embedding Model
    把文本变成向量，决定语义检索能力上限。
## 5. Vector Store
    负责存储和近似最近邻搜索
## 6. User Query
    用户查询问题
## 7. Query Embedding
    用户查询向量化
## 8. Retriever / Top-K / Threshold
    负责从向量库里找出最相关的K条文本，或者相似度超过某个阈值的文本。
## 9. Rerank 可选
    检索结果重排序
## 10. Prompt Assembly
    把问题和上下文拼给模型
## 11. LLM Generate
    基于上下文组织答案
## 12. Answer + Sources
    回家必须能追溯来源，否则不可生产化
