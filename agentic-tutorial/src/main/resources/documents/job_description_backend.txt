后端工程师（金融科技，安特卫普）
-----------------------------------
我们正在寻找一名**后端工程师**，帮助构建和完善支付与对账服务。你将主要使用 **Java（Spring Boot）**，与产品和运营团队紧密协作，确保可靠、可扩展的金融交易处理。

**职责：**
* 设计、实现和维护大规模支付和对账后端服务。
* 在云原生环境中使用 **PostgreSQL**、**Kafka**、**Docker** 和 **Kubernetes**。
* 专注于构建可靠、幂等的系统，具备强大的可观测性。
* 支持遗留服务迁移到现代 REST API。

**要求：**
* 有 Java 和 Spring Boot 后端开发专业经验。
* 对关系数据库和事件驱动架构有深入理解。
* 熟悉容器化和部署流水线。
* 有金融或定价系统经验者优先。
* 英语流利；荷兰语是加分项。
